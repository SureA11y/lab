    How to author workflows

    A workflow is usually a JSON object with a actions array. Each action is an object with a type and the fields that the action supports. 

    {
  "name": "Login flow",
  "actions": [
    { "type": "navigate", "url": "https://example.com/login" },
    { "type": "type", "selector": "#email", "text": "user@example.com" },
    { "type": "type", "selector": "#password", "text": "secret", "pressEnter": true },
    { "type": "waitForSelector", "selector": "main" },
    { "type": "a11yScan", "label": "Dashboard scan", "context": "main", "exclude": [".cookie", ".ads"] }
  ]
}
    About :ctx

    Inside forEachElement, use :ctx in selectors to target the current iterated element (or its descendants), for example :ctx a.details.

    About variables and templates

    Some strings support variable expansion, for example {var:name}, and iteration tokens like {index}, {oneBased}, {total}.

    Common use cases

    1) Scan a page, ignore noise

    {
  "actions": [
    { "type": "navigate", "url": "https://example.com" },
    { "type": "waitForSelector", "selector": "main" },
    { "type": "a11yScan", "label": "Main", "context": "main", "exclude": [".cookie", ".ads"] }
  ]
}

    2) Iterate navigation links and scan each destination

    {
  "actions": [
    {
      "type": "forEachElement",
      "targetSelector": "header nav a",
      "preActions": [
        { "type": "getText", "selector": ":ctx", "var": "scanTitle", "trim": true }
      ],
      "actions": [
        { "type": "click", "selector": ":ctx" },
        { "type": "waitForSelector", "selector": "main" },
        { "type": "a11yScan", "label": "{var:scanTitle}", "context": "main" },
        { "type": "goBack", "waitUntil": "domcontentloaded" }
      ]
    }
  ]
}

    3) Crawl a small site section within budgets

    {
  "actions": [
    {
      "type": "crawlQueue",
      "maxDepth": 2,
      "maxPages": 30,
      "sameOriginOnly": true,
      "include": "^https://example\\.com/",
      "exclude": "/(privacy|cookies|terms)/",
      "actions": [
        { "type": "a11yScan", "label": "Crawl page", "context": "main" }
      ]
    }
  ]
}
