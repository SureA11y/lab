How to check (5 steps)
  1. Click the browser's address bar, then press Tab repeatedly to move through every link and control on the page.
  2. At each stop, check that you can see where focus is, and that the order follows the reading order of the page.
  3. Operate each control with the keyboard (Enter, Space, arrow keys) and open and close menus and dialogs.
  4. Where something cannot be reached or used with the keyboard, check whether the page offers another way to do the same with the keyboard alone, such as previous and next buttons for a carousel, or move up and move down buttons for a list you can drag. It only counts if it does everything the mouse can.
  5. Check that focus never gets stuck inside a component and that Escape or Tab lets you move on.

Passes when: Everything works with the keyboard, directly or through another way that does the same job, focus moves in a sensible order and is always visible, and it never gets stuck.

Fails when: Something cannot be reached or used with the keyboard in any way, focus traps the user, the order is confusing, or focus is invisible, which fails WCAG 2.1.1, 2.1.2, 2.4.3 or 2.4.7.

How to fix: Tab through the page and check that every interactive element can be reached and used with the keyboard, and that focus can always leave it again; that the focus order follows the reading order, also after a script opens or adds content; and that the focus is always visible.
