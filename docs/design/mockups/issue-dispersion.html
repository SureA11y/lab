Where are the failures?

A proposal for showing how automatic failures are spread across the scans of a run: in the report view, and when comparing two or more reports. Every number below is computed in this page from generated data, the way the real feature would compute it when a report is shown.

Counted against scansAnalyzed, included scans. Not pages or URLs, so SPAs and repeated states work.
An issue is a failing ruleReach = share of scans where the rule fails. Element counts only add weight.
Automatic failures onlyCan't-tell results are mentioned in one line but never counted.
Computed, not storedWorked out when the report is shown, from the included scans. The JSON format stays as it is.
