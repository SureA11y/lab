Mockup · Where the failures are

Scan strips: filter by rule, and switch what the height counts

Two controls above the strips, the same in Compare and in the report view. The filter picks which rules the columns count. The toggle sets whether a column's height is the number of failing rules or the number of failing elements, on a square-root scale. They only change the strips; the rest of the section stays as it is. The data is made up.

States:
One set of controls per chartIn Compare, the filter and the toggle drive every strip at once, so you can read down to follow a rule across versions.
Same height scale, recomputedAll strips share one scale, taken from the tallest column after filtering. The status line names it (“Tallest column: 214 failing elements”).
Square root for elementsOne scan with 200 elements would flatten the rest on a linear scale. The square root keeps the order and leaves the small ones visible. The tooltip gives the exact count.
Colours keep their meaningPurple is still the report's widespread rules and orange the rest, whatever is selected. The thin baseline then means “none of the selected rules fail here”.
